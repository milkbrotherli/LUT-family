# LUT examples

This directory is reserved for outputs generated by the public Luma examples described in the main [README](../README.md). No generated LUT arrays or configuration records are bundled here: each example reads its pretrained input from `model-official/` and creates the required output directory at runtime. The examples cover the four LUT-processing steps in the five-stage LUT-ILF++ cascade:

```text
network -> Regular LUT -> fine-tuned Regular LUT -> Compact LUT -> fine-tuned Compact LUT
```

The paper uses the terms **Clipped LUT** and **Compacted LUT**. In the code and filenames, these correspond to **Regular LUT** and **Compact LUT**,
respectively.

## Runtime output map

| Generated directory | Pretrained source | Generated record |
| --- | --- | --- |
| `Y-Regular-LUT/` | bundled `Model_Y_860000.pth` | `transfer_config.json` |
| `Y-Regular-LUT-Finetuned/` | bundled Regular LUT, iteration 46000 | `finetune_config.json` |
| `Y-Compact-LUT/xyzt3i5/` | bundled Regular LUT, iteration 46000 | `compression_config.json` |
| `Y-Compact-LUT-Finetuned/xyzt3i5/` | bundled `xyzt3i5` Compact LUT, iteration 46000 | `finetune_config.json` |

`xyzt3i5` means `cd=xyzt`, `dw=3`, and `si=5`. Here `interval` is the Regular-LUT sampling shift, while `si` is the total non-diagonal sampling shift. The sparsification shift used in the paper is `Q = si - interval`; therefore, the default `interval=4, si=5` setting has `Q=1`. These values must remain unchanged when the same Compact LUT is converted, fine-tuned, and evaluated.
